# 🎬 CoolVideo – Wideo w galerii produktu dla PrestaShop 1.7 / 8 / 9

Lekki i prosty moduł umożliwiający dodanie wideo bezpośrednio do galerii zdjęć produktu.  
Obsługa YouTube, Vimeo oraz plików MP4.  
Pełna kompatybilność z PrestaShop 1.7, 8 i 9.

</div>

---

## 📌 O module CoolVideo

**CoolVideo** pozwala dodać wideo do galerii produktu — tam, gdzie klienci faktycznie je zobaczą.  
Film pojawia się jako element galerii, obok zdjęć, dzięki czemu prezentacja produktu jest bardziej atrakcyjna i zwiększa konwersję.

Moduł jest lekki, szybki i nie wymaga żadnych zmian w szablonie.

## 🚀 Funkcje modułu CoolVideo

### 🎥 Dodawanie wideo
- YouTube  
- Vimeo  
- MP4  
- automatyczne miniatury  
- ustawienie pozycji w galerii  

### 🎨 Wyświetlanie
- wideo jako element galerii zdjęć  
- odtwarzanie w miejscu zdjęcia lub w lightboxie  
- pełna responsywność  

### ⚙️ Panel administracyjny
- prosty formularz dodawania wideo  
- obsługa multistore  
- obsługa wielojęzyczności

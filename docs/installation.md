# Instalacja modułu CoolVideo

Moduł CoolVideo umożliwia dodanie wideo bezpośrednio do galerii zdjęć produktu w PrestaShop 1.7 / 8 / 9.

## Wymagania
- PrestaShop 1.7 / 8 / 9
- PHP 7.2+
- Brak dodatkowych bibliotek lub zależności

## Instalacja krok po kroku

### 1. Pobranie modułu
Pobierz paczkę ZIP z:
- sklepu PrestaExpert
- panelu klienta
- lub z sekcji Releases (jeśli dostępne)

### 2. Instalacja w PrestaShop
1. Zaloguj się do panelu administracyjnego.
2. Przejdź do **Moduły → Moduły i usługi**.
3. Kliknij **Dodaj nowy moduł**.
4. Wgraj plik ZIP.
5. Kliknij **Instaluj**.

### 3. Aktywacja
Po instalacji moduł jest automatycznie aktywowany.

### 4. Sprawdzenie działania
Przejdź do edycji dowolnego produktu → sekcja **Galeria**.  
Powinna pojawić się opcja **Dodaj wideo**.

Jeśli opcja jest widoczna — instalacja przebiegła poprawnie.
